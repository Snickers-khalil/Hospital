# Multi-Hospital

Multi-hospital management system (CodeIgniter).

## Setup

1. Copy `.env.example` to `.env` and configure database and app URL.
2. Ensure PHP, MySQL/MariaDB, and required extensions are available (e.g. via XAMPP).
3. Point your web server document root (or virtual host) at this project folder.
4. If dependencies are missing, run `composer install`.
